# ساعة الحروف والتشكيل

صفحة ويب تفاعلية بسيطة (ملف HTML واحد، بدون أي إعداد أو تثبيت) على شكل ساعة:

- **العقرب الكبير** يشاور على **الحرف** (٢٨ حرفًا حول الساعة).
- **العقرب الصغير** يشاور على **التشكيل** (فتحة، ضمة، كسرة، سكون، شدة، وتنوين الفتح/الضم/الكسر).
- في المنتصف يظهر ناتج الدمج مباشرة، مثل: **بَ**.

## طريقة الاستخدام

- اسحب أي عقرب حول الساعة (بالفأرة أو باللمس على الموبايل) لتدويره.
- أو اضغط مباشرة على أي مربع حرف بالخارج، أو مربع تشكيل بالداخل، ليتحرك العقرب المناسب إليه فورًا.

## التشغيل

الصفحة عبارة عن ملف واحد (`index.html`) بدون أي اعتمادات خارجية باستثناء خط عربي اختياري من Google Fonts (تعمل الصفحة بشكل طبيعي حتى بدون إنترنت). لتجربتها:

- افتح `index.html` مباشرة في أي متصفح (على الكمبيوتر أو الموبايل).
- أو فعّل GitHub Pages لهذا المستودع لتحصل على رابط تقدر تفتحه من الموبايل مباشرة.

## قريبًا

- نطق صوتي للحرف مع التشكيل (لم تتم إضافته بعد بحسب الطلب).
